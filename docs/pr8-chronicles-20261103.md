# 王国史の閲覧UI（2026-11-03）

対象：Draft PR #8 / `codex/prologue-companion-reunion-20261031`。

## 追加内容

保存済みの完成記録が1件以上あると、タイトルに「王国史」を表示する。未クリアでは非表示。起動時に既存の王国史を読み込むため、今回より前の完成記録でも解放される。新しい周回を始めても王国史は維持される。FIN到達直後からもタイトルへ戻って閲覧できる。

導線は「タイトル → 王国史一覧 → 記録詳細 → 一覧 → タイトル」。ヘッダーのタイトル名からも戻れる。詳細から一覧へ戻る際は一覧のスクロール位置を維持する。編集・削除の操作は追加しない。

一覧はクリア日時の新しい順。各記録にクリア日時・指揮官・実際の即位者・継承点／100・保存済みの総合評価を表示する。日時は保存時のUTC値を日本時間に変換して表示し、元データは変えない。

詳細には同行者、各都市で採用した政策、統治傾向と保存済みの集計、継承結果、終幕・エピローグ、八人の談話を表示する。同行者別の台詞抜粋は、会話の前後関係を失うため表示しない。長文は折りたたみ、開いた本文は画面高の65%までの領域内でスクロールして読める。本文は保存済み文字列だけを使い、新しい物語文章は生成しない。

## 作者検収後の表示修正

王国史詳細の「〇〇の後日談（保存本文）」欄をすべて非表示にした。既存の `companionAfterwordSnapshots` は保存・取得処理も含めて維持する。終幕・エピローグと八人の談話は、保存済みの全文と順序を従来どおり表示する。一覧・人物・点数・政策・統治傾向などは変更しない。

本編・正式原稿・保存処理・ゲームエンジン・内容版・画像は変更しない。

## 八人の談話の話者名

`src/chronicles.js` の閲覧処理で、記録の `contentVersion` に対応する正式原稿の「八人の談話」と、`ensembleAfterwordSnapshot` を照合する。全ブロックの順序と、保存時の段落区切り `\n\n` を含む文字列全体が完全一致した場合だけ、同じ位置の原稿ブロックから話者名を補う。

台詞の文字列を個別に検索したり、似た内容から話者を推測したりしない。同一文言が複数の人物に現れても、正式原稿の位置で区別する。地の文には名前を付けず、「一同」なども正式原稿の話者設定に従う。同じ話者の連続発言は名前を一つにまとめ、本文の段落・改行は保存値のまま維持する。顔画像や本編用の大きな会話UIは追加しない。

原稿がない内容版、本文の変更・欠落・重複・並べ替え・改行の違いがある記録は、名前なしの従来表示を維持する。話者の照合には現在の内容版へのフォールバックを使わない。未検証の条件分岐・置換を含む将来の原稿も、確実な対応を用意するまでは本文のみ表示する。

過去の正式終幕版・地図ひと言版・終幕読書UI版の3内容版で、従来の本文文字列だけの保存形式から復元できる。ローズモンド71点・アルフォンス即位の同形式の記録でも110ブロックすべてを照合した。保存データや保存形式の追加・移行・再保存は不要で、話者情報は閲覧中だけの表示値とする。

## 表示と保存の分離

- 即位者は保存済みの `sovereignId` を使う。71点のローズモンド周回は「指揮官：ローズモンド／即位者：アルフォンス／71／100」と表示する。点数や現在の判定規則から即位者を再計算しない。
- 政策は保存時の `labelAtCompletion`、本文は各スナップショットをそのまま使う。現在の原稿や政策名に置き換えない。
- 過去の内容版も登録済みの内容から人名・都市名を表示する。未対応の内容版は既知のIDの名前と保存値で可能な範囲を表示する。旧記録に即位者IDがなく、結果欄にも人物名が残っていなければ「記録なし」とし、推測しない。
- 一覧・詳細・本文の開閉・戻る操作は保存処理やゲームの状態遷移を呼ばない。保存枠、既読、王国史レコード、保存管理リビジョンを変更しない。閲覧での重複登録も発生しない。
- 王国史の読込み失敗は、ゲーム起動や既存記録の削除・初期化につなげず、読込みだけ再試行できる。

既存の保存形式・DB・内容版は変更しない。現在の内容版は `baumgarten-ending-reading-2026-11-03` のまま。物語・採点・継承判定・終幕画像は無変更。既存のFINロード復帰と、完成記録の重複防止も維持する。

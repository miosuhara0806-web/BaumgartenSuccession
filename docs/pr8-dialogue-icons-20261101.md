# PR #8 第2便・前半：会話UIと口調（2026-11-01）

## 基準と実装

対象ブランチ `codex/prologue-companion-reunion-20261031` のリモート最新 `410680785a2fde20271ee73fb90e854728fa4bc6` を取得して着手した。初期の `work` ブランチには変更を加えていない。新規CG・漫画・画像ファイルは追加していない。

- 複数話者の発言間の横線・上側パディングを除去し、間隔を12pxに縮小。話者名と本文の間隔も6pxに縮めた。
- `faceIcon` / `speakerLabel` を共通化。双子は既存の公式肖像、現王は既存の王国紋章、同行者8人とテオは既存の公式原画を使う。原画をCSSで顔の位置へ寄せ、PCは36px、スマホ幅は32pxで表示する。将来の複数人の会話でも同じ話者IDで利用できる。
- 王城・出発・再会の両陣営リスト、地図・試練の同行者一覧、会話ボタンを顔アイコンへ変更。話者名・人物名は文字で残し、装飾画像の代替テキストは空にする。画像が読めなくても名前と操作は残る。
- 王城のローズモンド経路は「ですが」→「少し間を置く。」→「兄上も、お気をつけて」を1ページにまとめた。同じ短文がある再会のアルフォンス経路も、前後のローズモンドの発言とまとめた。地の文には話者名や顔を付けない。
- チュートリアル正解後のローズモンド4発言だけを丁寧語へ分岐した。「西棟ですね」「倉庫から西棟までは運ばれています」「ですが、そこから式典準備室へ届ける指示が伝わっていません」「それなら、西棟の保管場所で止まっているはずです」。アルフォンスの文面は維持した。

## 保存・既読・進行

ページの変更は明示的な `pageGroup` の指定だけで、エンジン・保存処理は変更していない。最大4ブロック・合計220文字・長文の単独表示を維持する。指定は15グループ・47ブロックになり、王城の短い掛け合いはアルフォンス側3ページ、ローズモンド側4ページ。両経路とも全体で8グループを通る。

本文ID・順序・条件・contentVersion・保存形式version=1は維持する。地の文の本文と既読キーは変えず、変更したローズモンドの4ブロックだけ `textRevision` を1から2へ上げる。既存の44ブロックの表示補正と合わせて、本文を補正する対象は48ブロックとなる。保存済みのログ・旧内容版・得点・メモ・テオ回数は書き換えない。変更したページの各ブロック途中からのロードは、その位置以降だけを表示する。

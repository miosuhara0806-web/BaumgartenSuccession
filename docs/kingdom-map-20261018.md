地図は縦横比4:3、幅100%・自動高さで画像全体を表示する。トリミング、半透明化、色補正は行わない。中央エーレンフェルスを環状アルバが囲み、西アンカリング・東ヘクセレイ・南ルードという完成画像の地理を保持する。

縮小時に小さい地名を確認するため、「地図を拡大して見る」で1004×753の原寸画像を開ける。枠内は上下左右にスクロールでき、キーボードでも操作できる。通常の全体画像は残るため、全景を見失わず確認できる。

都市名を画像の上に重ねて追加しない。操作に必要な従来の都市ボタンは下へまとめ、未訪問／攻略中／完了・記録／準備中の判定と操作をそのまま使う。他都市は未実装のまま。

## Windows Edgeでの検収手順

1. 単独HTML `Baumgarten_MapReview_20261018.html` を、以前の版とは別名のままPCへ保存する。画像やCSSはすべて内部にあり、ほかのファイルを置く必要はない。
2. EdgeでHTMLを開く。「はじめから」→導入→指揮官→任意4人→出発と進める。
3. 地図の四辺・全景・色合い、肖像の対応を確認する。スマホ幅で地名が小さい場合は「地図を拡大して見る」を開き、枠内をスクロールする。
4. 地図の下のアルバボタンで3試練へ進む。通常A→C→Bで20点。帰還後は同じボタンから記録を開ける。
5. ZIPでも同じHTMLを提供する。実ファイルの保存先から「すべて展開」し、HTMLを開く。以前の版を削除する必要はない。
6. HTMLを直接開けない場合、Node.js導入済みPCで `node start-preview.cjs` を実行し、`http://127.0.0.1:4188/` を開く。停止はCtrl+C。

Windows版Edgeのローカル起動・実スマートフォンは美桜の端末での最終検収をお願いする。こちらの検証環境はLinux上のChromiumで、管理ブラウザの制約により `file://` 起動は検証していない。単独HTMLは追加ファイル不要で直接開ける構成を維持している。

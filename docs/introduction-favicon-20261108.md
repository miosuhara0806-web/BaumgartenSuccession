# 導入小説の表示と王国紋章アイコン

## 導入小説

全5都市・15試練の通常表示と再読表示の見出しを「導入小説」に統一する。開発用の日付・「正式原稿」は表示しない。試練名、本文、再読の閲覧専用案内は維持する。

アンカリング小試練②「認可には理由がある」とヘクセレイ大試練「知識の門を誰に開くか」では、原稿に入った固定改行と画面幅による折り返しが重なり、同じセリフが短い行に分断されていた。表示専用の明示リストを用いて、原稿の単独改行55か所中54か所を結合する。

| 対象 | 元の単独改行 | 表示時に結合 | 維持 | 段落数 |
| --- | ---: | ---: | ---: | ---: |
| アンカリング② | 30 | 29 | 1 | 38 |
| ヘクセレイ大試練 | 25 | 25 | 0 | 19 |

維持する1か所は、アンカリング②の段落28「原因の特定には時間がかかる。／一方で…」という地の文の対比。空行による正式な段落、会話と地の文の境界、引用符、句読点、文章順序を維持し、セリフ内の固定改行を残さない。正常な13本は加工対象にしない。

整形は `introductionText()` の表示用文字列だけに適用し、原稿・内容版・textRevision・既読キー・保存ログを変更しない。進行、得点、会話、テオ、王国史、戻る操作の処理は変更しない。PR #9の本文色・文字サイズを維持する。

追加テストでは、修正前mainの比較値を使い、正常13本×両主人公の本文HTML、全15本の元ブロックと既読キー、12内容版のデータ全体が不変であることを確認する。旧セーブの再開、再読時の保存不変、読了の一度だけの適用も検証する。

## 王国紋章アイコン

承認済みの青い盾・金色の生命樹・王冠のPNGを使用する。正式な国章 `src/assets/kingdom-emblem.svg` は維持する。

元画像は `src/assets/icons/life-tree-source.png` に無変更で保存する。SHA-256は `163f14579813c601dd5a1b0bb3b0147902b947793c9a6466bcc73829f1bcb095`。縮小版は再描画せず、可視アルファ領域に6元画像ピクセルの余裕を付けて切り出し、正方形の透明キャンバスから等比縮小した。透明色の縁を汚さないよう、乗算済みアルファでLanczos縮小を行う。

- 透過PNG：16、32、48、192、512px。
- Apple touch：180px。紙色背景で不透明化し、円形マスクでも王冠・盾が欠けない配置。
- Maskable：192、512px。紙色背景と、中央80%円内に紋章全体が収まる安全余白。
- ICO：16、32、48pxを内包。各フレームは対応するPNGと一致する。

HTMLのicon・apple-touch-icon、Manifestのiconsを更新し、仮の「樹」PNG4枚を削除する。新しいファイル名とバージョン付きURLでキャッシュ更新を促す。Manifestのid・start_url・scope・display等は変更しない。ローカルサーバーには `.ico` のMIME設定を1項目追加する。

## 通常公開用の範囲

Netlify検収専用の入口・データ・許可URL・ZIP作成処理は含めない。通常の `npm run build` で `dist/` にゲームとアイコンのみを生成する。GitHub Pagesワークフローは変更しない。

## 検証と再確認

```sh
npm test -- --test-concurrency=2
npm run check
node --check scripts/check-introduction-presentation-browser.cjs
npm run build
git diff --check
npm start
# 別ターミナルで実アプリを確認。必要に応じPLAYWRIGHT_MODULEとCHROMIUM_PATHを指定。
node scripts/check-introduction-presentation-browser.cjs
```

ブラウザ検証は検証専用の独立コンテキストで行い、既存の利用者の保存を使用しない。PC 1440px・スマホ390px／320pxで、両主人公・全15本の通常／再読、本文色・サイズ・段落余白・はみ出し、再読前後の保存・王国史の不変を確認する。

アイコンはPNG／ICOの読み込み、Manifest、原寸・明暗背景・円形マスクを確認する。実端末のホーム画面への追加は別途最終確認が必要。

反映後に古いアイコンが残る場合は、PCではCtrl+F5とタブの開き直しを試す。スマホでは通常タブを再読み込みし、必要ならホーム画面ショートカットを作り直す。セーブ保護のためサイトデータを削除しない。

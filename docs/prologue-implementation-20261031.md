## 実装した動作

継承戦宣言 → 主人公選択 → 専用調査「消えた式典の飾り」 → 8名の紹介・4名選抜 → 主人公側4名だけの2×2最終確認 → 双方の一行が決まる王城会話 → 翌朝の出発 → 自由な通常4都市の地図、という流れを追加した。王城会話と再会には双方の4名の名前を表示する。相手側の点数や進捗は作らない。

調査は王城倉庫・使用人詰所・式典準備室の任意順。各地点の本文読了で調査済みを記録し、全3地点の確認後に判断を解放する。再確認で調査記録は増えない。A/Cは無罰で再挑戦でき、B正解後は会話を終えてから選抜へ移る。調査は通常15試練・得点・統治タグ・都市数・訪問順・本編の情報メモ・テオ回数を変更しない。

同行者の一覧は出身地と正式な一言紹介を表示し、年齢や戦闘役割は表示しない。詳細は既存の年齢・出身地を維持し、正式な人物紹介・旅で活きる視点・本人の一言を表示する。4人未満で確定不可、5人目は選択不可、選び直しは選択を維持する。決定後は変更できず、残る4人を既存の補集合処理で相手側に固定する。

通常都市2つ目の完了直後に、街道沿いの宿場で双子の再会を挿入する。本文は主人公別の2パターンだけで、編成別の分岐は作らない。イベント画面には通常試練UI・採点・テオ欄を表示せず、最後の確認後に操作可能な地図へ戻る。

## 設計判断と互換性

- 新規周回の contentVersion は `alba-hexerei-anchoring-rude-ehrenfels-prologue-reunion-2026-10-31`。直前の同行者会話統一版を複製して、序章用の場面・人物紹介・画像対応・再会だけを追加する。旧8内容版の登録を残し、旧セーブは元の定義で再開する。
- 周回の `schemaVersion`、IndexedDB の保存形式版、スロット版はすべて **1のまま**。`src/storage.js` は変更していない。新しい `run.tutorial` は新内容版だけが使用し、旧セーブには要求しない。
- 調査の開始・調査済み地点・判断解放・正解・正解後会話処理済みは `run.tutorial`、現在段階と本文位置は既存の `run.position` に保存する。画面の表示から完了処理は行わず、エンジンの確認操作でのみ進める。
- 追加操作も既存 `perform` → `commitAuto` の保存経路を使用する。途中再開、失敗時の再試行、既読履歴と周回記録の分離を維持する。
- 再会は既存 `afterTwoRegions` イベントを使用する。都市終了場面の完了 → 都市の completed 記録 → イベント開始 → 地図、という既存の順序をそのまま使う。途中位置・完了状態は周回内保存で、共通既読とは独立する。
- 現行のアルバ終了場面には本文があり、他4都市の終了場面は空。本文がある場合は読了後、空の場合は大試練結果からの進行確定後にイベントを判定する。既存都市本文は追加・変更していない。
- `support.king`（現王）と `support.overseer`（監督官）を話者登録し、宰相・テオと区別する。各候補に別の監督官が同行する説明を序章に含める。既存都市の宰相の役割と台詞は保持する。
- 画像9枚は受領PNGと同じバイト列。ID・画像パス・顔位置は内容データに固定する。一覧・最終確認はCSSによる正方形クロップ、詳細は全原画を自然な縦横比で表示する。サンドロ原画だけ603×753、他8枚は502×753だが、すべて原画全体を維持する。
- テオ画像は `support.theo` にのみ登録して保管し、8人の選抜候補に含めない。画像データをセーブへ埋め込まない。画像失敗時は画像だけを隠し、名前・説明・操作を維持する。

5都市・15試練の定義、既存本文ブロック、同行者会話、情報、テオ定義は旧版と完全一致することを自動検証する。アルバ小②のDはリゼット同行＋当該周回の当該会話完了でのみ解放し、D=4/C=5を維持する。テオの全都市2回・各都市1回・キャンセル非消費、通常4都市後の王都解放も維持する。

# 同行者会話の表示改善（2026-10-18）

基点はアルバ章検収版 `a31cd0f`。開始時の未反映変更なし。

## 修正内容

- 同行者1人の3発言を、段落の余白を設けて同じ枠に表示。長文は枠内スクロールで読める。
- 「確認して戻る」1回で、残りの発言の読了・既読・会話完了・元の試練への復帰を一括保存。開いただけでは読了しない。
- 該当会話の確認完了時だけ、吹き出しが消えて小②のリゼットDが開放される。会話による加点はない。
- 既読スキップは既読の残り発言を一括確認し、未読では進めない。
- 会話ログは同じ会話・場面・話者の連続した発言をまとめる。ログを開いても既読や得点は変わらない。
- 通知による再描画でも会話枠内のスクロール位置を保持する。

## 維持したもの

会話データは元の3発言のまま。本文・順序・句読点、表示対象・条件、内容版、進行エンジン、保存形式、200発言のログ記録は変更しない。

会話途中の旧セーブは、すでに確認した発言を重複記録せず、残りを一括確認できる。新旧の周回とも従来の内容版で読み込む。

導入小説3本と縦スクロール、選択肢・配点・評価理由、情報メモ、テオ、編成、画像・地図・PWAは変更しない。通常9択の反応本文など、前回の原稿待ち項目もそのまま。

## 検収方法

1. 新しいZIPをすべて展開し、中のHTMLをPCのChrome/Edgeで開く。以前のファイルは残す。
2. リゼットを含む4人でアルバへ。吹き出しから3発言が同じ枠で読めることを確認する。
3. 小②の会話前を手動1に保存。リゼットの会話を開くだけでは確認済みにならず、再読み込み後も未確認の会話へ戻ることを確認する。
4. 「確認して戻る」を押す。吹き出しが消えてDが出ること、点数が増えないことを確認し、手動2へ保存する。
5. 手動1をロードするとDは消える。リゼット会話で既読スキップすると再開放する。手動2では確認済みとDが維持される。
6. 会話ログで3発言をまとめて読み返す。PC・スマホ相当の幅で、最後の発言までスクロールして読めることを確認する。

別名の検収HTMLとZIPは `python scripts/package-alba-preview.py --edition conversation` で生成する。
保存先は専用DB。10月16日版・前回検収版・公開版の保存を置き換えず、自動取り込みもしない。

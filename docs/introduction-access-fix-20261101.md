1. `chapterProgress`が未開始なら未到達。
2. 当該試練の`trialResults`があれば到達済み。
3. 未確定の場合、地域の`resumePosition`、または現在位置／会話・テオの`returnPosition`が当該試練の`trial`位置なら到達済み。

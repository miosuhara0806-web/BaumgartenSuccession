## 検収方法

1. 新しいZIPをすべて展開し、中のHTMLをPCのChrome/Edgeで開く。以前の版は残す。
2. 新規周回で通常A/B/Cの本文・評価理由・点数を読む。A→C→Bで20点、B→A→Aで13点。
3. ハロルド・フレデリカ・リゼット・サンドロで会話を聞く。小①3件・小②4件・大3件の固有メモが、確認後にだけ表示されることを確認する。
4. 小②のリゼット会話前を手動1に保存、確認後を手動2に保存。ロードするとメモとDが連動して未取得／取得済みに戻る。既読スキップでも取得できる。
5. 大試練の政策提出前にテオを依頼する。報告と「過去の防衛訓練の中断」、出典「テオ／防衛隊の内部記録」、残数を確認する。依頼なしでも政策Bは10点。
6. 都市完了後、アルバ記録と情報メモを開く。全会話と調査を取得した場合は共通12＋固有10＋テオ1＝23件。DありのA→D→Bは19点。

# Title font assets

Shippori Mincho (400 / 600), by The Shippori Mincho Project Authors.
Source: https://github.com/google/fonts/tree/main/ofl/shipporimincho
Upstream: https://github.com/fontdasu/ShipporiMincho
License: SIL Open Font License 1.1; see OFL-ShipporiMincho.txt.

The WOFF2 files were obtained from the official Google Fonts CSS2 API on
2026-10-06 with `family=Shippori+Mincho:wght@400;600` and `text=` restricted to:

王国史の、一頁へ。バウムガルテン継承戦誰を連れているかで同じでも見えものが変わる

They are self-hosted and only used by the title, eyebrow and short lead copy.
Total font payload: 19,272 bytes. No runtime Google Fonts request is needed.
`font-display: swap` keeps text visible with system serif fallbacks.
If this copy changes, update the subsets to cover any newly introduced characters.

## Main title logo

Kaisei Decol Bold (700), source:
https://github.com/google/fonts/tree/main/ofl/kaiseidecol
License: SIL Open Font License 1.1; see OFL-KaiseiDecol.txt.

The official Google Fonts CSS2 subset, retrieved on 2026-10-06, contains only
`バウムガルテン王国の継承戦` and is 3,936 bytes. It is used only for the
main title. The eyebrow and lead retain Shippori Mincho 400; body/UI stay unchanged.
